DECORA INDUSTRIES — HERO VIDEO PLACEHOLDER
============================================
The cinematic hero uses a pre-rendered background video. This site works
WITHOUT it (a poster image + CSS fallback renders instead), but for the
full effect, add the following two files to this folder:

  hero-showroom.webm   (preferred — VP9/AV1, smaller)
  hero-showroom.mp4    (fallback — H.264, universal)

Recommended specs:
  - Resolution: 1920x1080 desktop (1280x720 acceptable for smaller size)
  - Duration: 8-15 seconds, seamless loop
  - Muted, no embedded text
  - Darker/neutral area behind hero copy for readability
  - Optimised bitrate (2-4 Mbps) for fast load

Also replace hero-poster.svg with hero-poster.webp (1920x1080, ~150KB).
See README.md > "Replacing the Hero Video" for full instructions.
